# for you 🤍

A little website I made — no birthday, no anniversary, no occasion. Just something built because I felt like it.

## What's inside

- A lock screen (because some things are just for one person)
- A room full of small things — memories, songs, letters, little things I love
- A hidden corner, for whoever's curious enough to look

## Built with

Plain HTML, CSS, and JavaScript — no frameworks, no build step. Just open `index.html` in a browser.

## Structure

- `index.html` — all the scenes
- `style.css` — how it looks
- `script.js` — how it behaves
- `config.js` — all the personal content (names, passwords, photos, letters, songs)
- `images/` — photos used across the site

## Note

This is a personal project, not a template — the content in `config.js` is specific to one person. Feel free to look around, but the passwords stay mine.
